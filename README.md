## about

I'm an **AI Engineer and Full-Stack Developer** based in Dipolog City, Philippines. I build systems where AI is part of the product rather than a demo — speech-to-text, conversational models and retrieval-augmented generation wired into production-shaped applications.

I take an idea the whole way: **concept → architecture → implementation → deployment**.

```console
> run pipeline --from concept --to deployment

stage 2  architecture   services, schema, interfaces
stage 3  implementation voice, retrieval, tool calls
stage 4  deployment     ship, monitor, iterate
```
